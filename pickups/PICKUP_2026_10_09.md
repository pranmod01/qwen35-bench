     | PAM | ~3,300–3,500 pairs | ~70 tokens per image+word pair |

     - Concept count only binds if a list needs ~3,500 *unique* concepts; THINGS already reaches 3,500 in
       serial order with 2 photos per concept.

       many are abstract, rare or noisy. Random draws would put near-duplicates in one list and use them as
       foils. Proposed: leaf synsets with a minimum WordNet distance between any two picked; start from the
       filtered ImageNet-21k-P (winter21, ~10.5k classes).

       66 tokens, matching Brady and THINGS-256.

       images is untested on the larger models (item 7). Needs H100 / RTX PRO 6000.

       storage (home quota, item 67), and the user runs the download via `!` (login node kills long jobs).
